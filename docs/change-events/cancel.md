---
title: Cancel or Delete
sidebar_position: 1
---

If a published event is no longer taking place:

- Mark canceled using the **Cancel Button** if it was promoted beyond the calendar (on a poster, in a newsletter, or online), or has been listed for longer than two weeks.
- Use **Cancel Button** if the event is widely advertised or is part of a regular weekly series when regular patrons would expect it to occur. 

Only events that never been promoted, and have been listed for less than two weeks, should be removed entirely.

Only delete events when we can expect no patron has already planned to attend. Delete events that were added erroneously, such as during holiday or several months in the future. Contact Shared Systems to delete.

Events affected by a temporary closure follow the same rules.

| Delete Event | Cancel Event |
| --- | --- |
| Event is erroneous | Event is advertised |
| Event is not part of a regular series | Event is part of a regular, weekly series. Patrons would still show up, even if the event were deleted |
| There is a duplicate event | Event falls during a period when the location is temporarily closed |
| Event falls on holiday-closed dates | |

### Rescheduled

- **Time change only**: When a time changes but the date stays the same, update the existing event listing with the new time.
- **Date change**: Cancel or delete the original event based on the rules above. Submit the new date as a new event.

### Extended closure

  - During the period when we are _not_ offering any in-person events, for a period longer than two weeks.
  - Delete in-person events from Bedework for the affected period.
  - Add any replacement events at other sites as new events. 

### Approval queue

Events in the Approval Queue should never be marked canceled. Remove them from the series using the **Delete** button in the top-right corner of the event instance.
